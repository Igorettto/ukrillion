# 🦑 Крільйон

**«Крільйон»** — це інтелектуальна вебгра українською мовою, створена за мотивами популярного ігрового формату Krillion. 

Головна мета гри — дати **найрідкіснішу та найменш очевидну правильну відповідь** на кожне із 7 запитань раунду. Чим менше людей згадають вашу відповідь, тим більше балів ви отримаєте!

> ⚠️ **ЗВЕРНІТЬ УВАГУ:** Проєкт наразі перебуває на стадії **активної розробки**. База питань, баланс рівнів рідкісності та функціонал будуть змінені.

---

## 🎯 Правила гри та Шкала рідкісності

У кожному раунді гравець отримує 7 запитань зі скінченним і точним переліком правильних відповідей. Залежно від того, наскільки рідкісним є введений варіант, відповіді розподіляються за 5 тірами:

| Тір | Назва | Бали | Опис |
| :--- | :--- | :---: | :--- |
| 🟣 **One in Krillion** | Один на крільйон | **1000** | Екстремально рідкісна або унікальна відповідь (суворо 1–2 варіанти на питання). |
| 🔵 **Deep Cut** | Глибинна знахідка | **400** | Маловідомий факт для справжніх ерудитів (3–5 варіантів). |
| 🟢 **Rare** | Рідкісна | **200** | Неочевидна правильна відповідь. |
| 🟠 **Schooler** | Косякова риба | **75** | Поширена стандартна відповідь зі шкільної програми. |
| 🔴 **Plankton** | Планктон | **20** | Найдефолтніший і найпопулярніший варіант, який спадає на думку кожному. |
| ⚪ **Miss** | Мимо / Не знайдено | **0** | Відповідь відсутня в базі або введена з помилкою. |

💡 **Механіка повторної спроби:** Якщо введеного слова немає в базі, гра **не зараховує промах одразу**, а дає можливість спробувати ввести інший варіант або пропустити питання.

## 🛠 Технологічний стек

- **Фреймворк:** [React 18](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Стилізація:** Pure CSS / Tailwind CSS
- **Алгоритм зіставлення:** 
  - Нормалізація українського тексту (апострофи, відмінки, очищення від слів-маркерів «річка», «протока», «кістка»).
  - Нечіткий пошук за відстанню Левенштейна (Levenshtein distance) для врахування описок.
